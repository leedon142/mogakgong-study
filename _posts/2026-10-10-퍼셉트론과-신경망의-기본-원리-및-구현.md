## 주요 내용

### 퍼셉트론의 동작 원리

퍼셉트론은 여러 입력에 각각 가중치를 곱하고 편향을 더한 뒤, 계산 결과에 따라 0 또는 1을 출력하는 알고리즘이다. 가중치는 각 입력의 영향력을 조절하고, 편향은 뉴런이 활성화되는 기준을 조절한다.

입력을 `x`, 가중치를 `w`, 편향을 `b`라고 하면 퍼셉트론은 다음과 같이 표현할 수 있다.

```text
y = 0  (w₁x₁ + w₂x₂ + b ≤ 0)
y = 1  (w₁x₁ + w₂x₂ + b > 0)
```

같은 퍼셉트론 구조라도 가중치와 편향을 다르게 설정하면 AND, NAND, OR 논리 회로를 구현할 수 있다.

```python
import numpy as np


def AND(x1, x2):
    x = np.array([x1, x2])
    w = np.array([0.5, 0.5])
    b = -0.7
    return int(np.sum(w * x) + b > 0)


def NAND(x1, x2):
    x = np.array([x1, x2])
    w = np.array([-0.5, -0.5])
    b = 0.7
    return int(np.sum(w * x) + b > 0)


def OR(x1, x2):
    x = np.array([x1, x2])
    w = np.array([0.5, 0.5])
    b = -0.2
    return int(np.sum(w * x) + b > 0)
```

### 단층 퍼셉트론의 한계와 XOR

단층 퍼셉트론은 하나의 직선으로 구분할 수 있는 선형 문제를 처리할 수 있지만 XOR 문제는 해결할 수 없다. XOR는 두 입력이 서로 다를 때만 1을 출력하므로 하나의 직선만으로 출력 영역을 나눌 수 없기 때문이다.

하지만 NAND와 OR의 결과를 AND 퍼셉트론에 입력하는 방식으로 층을 여러 개 연결하면 XOR를 구현할 수 있다. 이를 통해 단순한 요소를 조합하고 층을 깊게 만들면 더 복잡한 문제를 표현할 수 있다는 점을 확인했다.

```python
def XOR(x1, x2):
    s1 = NAND(x1, x2)
    s2 = OR(x1, x2)
    return AND(s1, s2)
```

### 신경망의 구조

신경망은 입력층, 은닉층, 출력층으로 구성된다. 입력층은 데이터를 받아들이고, 은닉층은 가중합과 활성화 함수 계산을 수행하며, 출력층은 문제에 맞는 최종 결과를 만든다. 퍼셉트론과 달리 신경망에서는 활성화 함수를 이용해 신호를 연속적인 값으로 변환할 수 있다.

각 층의 계산은 다음과 같이 행렬 곱으로 표현할 수 있다.

```text
A = XW + B
Z = h(A)
```

여기서 `X`는 입력, `W`는 가중치, `B`는 편향, `h`는 활성화 함수이다. 행렬 연산을 사용하면 여러 입력과 뉴런의 계산을 한 번에 처리할 수 있다.

### 활성화 함수

- 계단 함수: 입력이 기준을 넘는지에 따라 0 또는 1을 출력한다.
- 시그모이드 함수: 입력을 0과 1 사이의 연속적인 값으로 변환한다.
- ReLU 함수: 입력이 0 이하면 0, 0보다 크면 입력값을 그대로 출력한다.
- 출력층의 활성화 함수: 회귀에서는 항등 함수를, 분류에서는 주로 소프트맥스 함수를 사용한다.

```python
def sigmoid(x):
    return 1 / (1 + np.exp(-x))


def relu(x):
    return np.maximum(0, x)


def softmax(x):
    x = x - np.max(x)
    exp_x = np.exp(x)
    return exp_x / np.sum(exp_x)
```

## 막힌 점과 해결 과정

- 문제: XOR가 단층 퍼셉트론으로 구현되지 않는 이유가 직관적으로 와닿지 않았다.
- 해결 과정: XOR의 진리표를 좌표 평면에 표시하고, 출력값이 다른 영역을 하나의 직선으로 나눌 수 없다는 것을 확인했다.
- 해결 방법: NAND, OR, AND 퍼셉트론을 순서대로 조합하여 비선형 영역을 여러 층으로 표현했다.
