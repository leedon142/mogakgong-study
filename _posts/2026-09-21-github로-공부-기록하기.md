## 오늘의 목표

- GitHub에 스터디 기록을 남기는 방법 익히기
- Markdown 문법으로 간단한 글 작성하기

## 공부한 내용

오늘은 GitHub 저장소에 Markdown 파일을 만들고, 그 파일을 블로그 글로 공개하는 방법을 연습했다.

글 위쪽의 `title`, `date`, `categories`, `tags`는 글의 기본 정보를 나타낸다. 그 아래에는 `##`를 사용해 내용을 주제별로 나눌 수 있다.

## 핵심 정리

- 글은 `_posts` 폴더에 저장한다.
- 파일 이름은 `연도-월-일-제목.md` 형식으로 작성한다.
- 내용을 수정한 뒤 커밋하면 블로그에도 자동으로 반영된다.
- 완벽하게 쓰려고 고민하기보다 짧게라도 꾸준히 남기는 것이 중요하다.

## 막혔던 부분과 해결 방법

처음에는 GitHub 저장소와 블로그가 서로 다른 것이라고 생각했다. GitHub Pages를 사용하면 저장소에 올린 글이 자동으로 블로그에 표시된다는 것을 알게 되었다.

## 느낀 점

생각보다 작성 방법이 간단했다. 공부가 끝난 뒤 오늘 배운 내용 세 가지만 적어도 좋은 기록이 될 것 같다.
