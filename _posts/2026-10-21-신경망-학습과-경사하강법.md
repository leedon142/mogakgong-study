## 이번 회차에 한 일

지난 회차까지는 정해진 가중치로 결과를 **예측**만 했다. 이번에는 처음으로 가중치를 **바꾸는** 과정, 즉 학습을 다뤘다. 손실 함수 → 수치 미분 → 미니배치 경사하강법 순서로, 팀원마다 한 단계씩 맡아 정리했다.

- 정답 확률에 따라 제곱 오차와 교차 엔트로피가 어떻게 달라지는지 비교
- `f(x, y) = x² + y²`로 수치 미분과 기울기 계산
- 80개 데이터를 학습 64개 / 평가 16개로 나누고 미니배치 학습 300회
- 학습률 0.5와 0.1의 결과 비교

## 핵심 정리

### 1. 손실 함수 비교

정답 클래스가 1일 때, 모델이 정답에 준 확률에 따른 손실 값이다.

| 예측 확률 | 정답 확률 | 제곱 오차 | 교차 엔트로피 |
| --- | --- | --- | --- |
| `[0.1, 0.9]` | 0.9 | 0.01 | **0.1054** |
| `[0.9, 0.1]` | 0.1 | 0.81 | **2.3026** |

정답에 낮은 확률을 줄수록 교차 엔트로피가 급격히 커진다.

### 2. 수치 미분과 경사하강법

입력을 아주 조금 늘렸을 때와 줄였을 때의 차이로 변화율을 구한다. 가중치가 여러 개면 **하나씩만** 바꿔 가며 각각의 영향을 확인한다.

```python
def numerical_gradient(f, x, h=1e-4):
    grad = np.zeros_like(x)
    for i in range(x.size):
        original = x[i]
        x[i] = original + h
        f_plus = f(x)
        x[i] = original - h
        f_minus = f(x)
        grad[i] = (f_plus - f_minus) / (2 * h)
        x[i] = original  # 반드시 원래 값으로 되돌린다
    return grad

# 기울기의 반대 방향으로 학습률만큼 이동
W -= learning_rate * grad
```

`f(x, y) = x² + y²`의 (3, 4)에서 기울기는 `[6.0, 8.0]`으로, 미분 공식 `(2x, 2y)`와 일치했다.

### 3. 미니배치 학습 결과 (학습률 0.5)

| 갱신 횟수 | 전체 학습 손실 | 학습 정확도 |
| ---: | ---: | ---: |
| 0 (학습 전) | 0.6962 | – |
| 50 | 0.6021 | 96.9% |
| 100 | 0.3479 | 100.0% |
| 150 | 0.1555 | 100.0% |
| 200 | 0.0862 | 100.0% |
| 250 | 0.0611 | 100.0% |
| 300 | **0.0412** | 100.0% |

100회 이후 정확도는 이미 100%인데 손실은 계속 줄어든다. 정답은 이미 맞히고 있지만 **정답에 주는 확률이 점점 확실해지고 있다**는 뜻이다. 손실과 정확도가 다르다는 걸 숫자로 확인한 부분.

### 4. 학습률 비교

| 학습률 | 300회 후 학습 손실 |
| ---: | ---: |
| 0.5 | 0.0412 |
| 0.1 | 0.5606 |

같은 반복 횟수 안에서는 학습률이 학습 속도를 크게 바꿨다. 다만 이 결과만으로 "큰 학습률이 항상 좋다"고 할 수는 없다.

### 5. 평가 데이터

학습에 쓰지 않은 16개로 평가한 정확도는 **100%**였다. 하지만 경계 근처의 애매한 표본을 뺀 작은 예제이므로 실제 문제의 성능으로 일반화할 수는 없다. 평가 데이터는 가중치 수정에 쓰지 않고, 학습이 끝난 뒤 확인용으로만 쓴다.

## 회고와 다음 계획

- 미분이 수학 문제 풀이용이 아니라 **가중치를 고치는 데 직접 쓰인다**는 게 인상적이었다.
- 학습률과 반복 횟수에 따라 결과가 달라지므로, 조건을 바꿔 가며 비교하는 습관을 들이기로 했다.
- 수치 미분은 직관적이지만 가중치가 많으면 너무 느리다. 다음 회차에서는 기울기를 효율적으로 구하는 **오차역전파법**(5장)을 공부한다.
- 학습 손실이 낮아도 새로운 데이터에서 틀릴 수 있는 이유(과적합)도 함께 알아보고 싶다.
