## 이번 회차에 한 일

지난 회차에 퍼셉트론과 신경망의 구조를 봤다면, 이번에는 신경망이 **입력을 받아 예측 결과를 내기까지**의 과정을 끝까지 따라갔다. 세 명이 각자 다른 부분에 초점을 맞춰 공부한 뒤 서로 설명해 주는 방식으로 진행했다.

- 계단 · 시그모이드 · ReLU 함수의 출력 비교
- `2 → 3 → 2` 크기의 작은 신경망을 직접 계산하며 배열 모양(shape) 확인
- 오버플로 없이 계산하는 softmax 구현과 배치 처리
- 준비된 가중치로 손글씨 숫자 360개를 분류하고 정확도 계산

## 핵심 정리

### 1. 활성화 함수 비교

같은 입력 `[-2, -1, 0, 1, 2]`를 넣었을 때의 출력이다.

| 함수 | 출력 | 특징 |
| --- | --- | --- |
| 계단 | `[0, 0, 0, 1, 1]` | 기준을 넘는 순간 값이 갑자기 바뀐다 |
| 시그모이드 | `[0.119, 0.269, 0.5, 0.731, 0.881]` | 0과 1 사이에서 부드럽게 변한다 |
| ReLU | `[0, 0, 0, 1, 2]` | 음수는 0, 양수는 그대로 |

### 2. 배열 모양 따라가기

입력이 2개, 은닉 뉴런이 3개, 출력이 2개인 신경망에서 각 층의 모양은 이렇게 이어진다.

```text
X (1, 2)  ·  W1 (2, 3)  →  a1 (1, 3)  →  sigmoid  →  z1 (1, 3)
z1 (1, 3) ·  W2 (3, 2)  →  scores (1, 2)  →  softmax  →  확률 (1, 2)
```

실제 실행 결과는 `a1 = [1.0, 1.3, 1.6]`, `z1 = [0.731, 0.786, 0.832]`, 최종 확률 `[0.534, 0.466]`으로 클래스 0을 예측했다.

### 3. 안정적인 softmax

지수 함수에 큰 값을 바로 넣으면 계산 범위를 넘어간다. 모든 점수에서 최댓값을 빼도 확률은 그대로이므로, 이를 이용해 안전하게 계산한다.

```python
def softmax(x):
    x = x - np.max(x, axis=-1, keepdims=True)  # 최댓값을 빼서 오버플로 방지
    exp_x = np.exp(x)
    return exp_x / np.sum(exp_x, axis=-1, keepdims=True)
```

`softmax([1000, 1001, 1002])`처럼 큰 값을 넣어도 결과가 모두 유한한 값인지 `assert`로 확인했다.

### 4. 손글씨 숫자 분류 (학습 아님)

| 항목 | 값 |
| --- | --- |
| 입력 데이터 | `(360, 64)` — 8×8 이미지 360장 |
| 가중치 | `W1 (64, 32)`, `W2 (32, 10)` |
| 정확도 | **350 / 360 = 97.2%** |
| 배치 검증 | 한 장씩 / 전체 / 50장씩 계산한 결과가 모두 일치 |

배치 처리는 여러 장을 한꺼번에 계산하는 방법일 뿐, **학습을 의미하지 않는다**는 점을 팀원 모두 강조했다.
